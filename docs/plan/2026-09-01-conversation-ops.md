## 원본 메뉴 (실측)

사이드바 항목의 `[data-testid="history-item-N-options"]` 를 누르면 6개가 나온다.

| 항목 | 우리 구현 |
|---|---|
| 공유하기 | ✓ (원본 대화상자를 연다) |
| 이름 바꾸기 | ✓ |
| 채팅 고정 | ✓ |
| 아카이브에 보관 | ✓ |
| 삭제 (`delete-chat-menu-item`) | ✓ (확인 절차 필요) |
| 프로젝트로 이동 | ✓ |

## 왜 원본 메뉴를 클릭하지 않고 API 를 부르는가

모델 선택기(`picker.js`)는 원본 메뉴를 조작한다. 전송 상태를 원본이 들고 있어서 다른 길이 없기 때문이다.
**대화 조작은 다르다.** 상태가 서버에 있고 우리 목록도 이미 API 에서 온다.
게다가 원본 사이드바는 **창이 좁으면 DOM 에 아예 없어서** 클릭할 대상 자체가 없다.

## 검증한 엔드포인트

전부 `PATCH /backend-api/conversation/<id>` 다. 내가 만든 테스트 대화에서 **왕복까지** 확인했다.

| 동작 | 본문 | 확인 |
|---|---|---|
| 이름 바꾸기 | `{title}` | 200 `{success:true}`, GET 으로 반영 확인, 원래 이름으로 복원 |
| 고정 | `{is_starred}` | `pinned_time` 이 설정되고 `false` 로 해제됨 |
| 보관 | `{is_archived}` | 목록에서 사라지고 `false` 로 복귀 |
| 삭제 | `{is_visible:false}` | 200, 목록에서 사라짐, **복구 불가 확인** |

### 삭제는 되돌릴 수 없다 (2026-09-01 실측)

버릴 대화를 하나 만들어 직접 확인했다.

| 단계 | 결과 |
|---|---|
| `PATCH {is_visible:false}` | 200 `{success:true}` |
| 삭제 후 목록 | 사라짐 |
| 삭제 후 `GET /backend-api/conversation/<id>` | **404** |
| `PATCH {is_visible:true}` 로 복구 시도 | **404 — 실패** |

그 id 로는 더 이상 닿을 수 없다. **`:undo` 를 줄 수 없다.**
검증 전에는 "소프트 삭제일 테니 복구되겠지"라고 가정하고 안전 설계를 느슨하게 갈 뻔했다.

## 안전 장치

되돌릴 수 없는 동작은 확인 없이 실행되지 않는다.

- 명령: `:rm <n|id>` 는 대상만 보여주고 멈춘다. 실행하려면 `:rm <id> yes`
- 메뉴: '삭제'를 누르면 `정말 삭제? 한 번 더` 로 바뀐다. 4초 안에 다시 눌러야 실행된다
- 보관은 되돌릴 수 있으므로 즉시 실행하되 되돌리는 방법을 함께 안내한다

**모달(`prompt`/`confirm`)은 쓰지 않는다.** 페이지를 막고 터미널 UX 를 깬다.
이름 바꾸기는 입력줄에 `:rename <id> <현재 이름>` 을 채워주고 편집하게 한다.

## 안 하는 두 가지

**공유하기** — 대화를 **공개 링크**로 만든다. 우리 UI 에서 한 번 클릭으로 공개되면 안 된다.
원본의 확인 절차를 거치는 게 맞다고 판단했다. `:q` 로 원본에서.

**프로젝트로 이동** — 프로젝트 선택 UI 가 필요하고 엔드포인트도 미검증이다.

## 다중 삭제 (원본에 없는 기능)

사이드바 행의 ⋯ → **선택 모드**, 또는 `:select`.
체크박스로 여러 개를 고르고 아래 버튼으로 삭제·보관한다. `esc` 로 나간다.

되돌릴 수 없는 일을 한 번에 여러 건 하므로 장치를 겹쳤다.

1. **두 단계 확인** — `삭제` 를 누르면 `N개 · 되돌릴 수 없다` + `정말 삭제` 로 바뀐다
2. **무엇을 지우는지 먼저 기록** — 실행 전에 id 앞자리와 제목을 스크롤백에 남긴다.
   되돌릴 수 없으니 기록이라도 있어야 한다
3. **부분 실패로 멈추지 않는다** — 순차로 끝까지 돌리고 성공/실패를 나눠 보고한다.
   병렬로 쏘면 어디까지 지워졌는지 말할 수 없게 된다
4. **진행 표시** — `삭제 중 3/12`

보관은 되돌릴 수 있으므로 확인 단계 없이 바로 실행한다.

## 조작 방법

```
목록 행에 마우스를 올리면 ⋯ 가 뜬다. 우클릭도 같은 메뉴.

:rename <n|id> <새 이름>
:pin <n|id> [off]
:archive <n|id> [off]
:rm <n|id> yes
```

대상은 `ls` 번호, 대화 id 앞자리, 제목 일부 중 아무거나 된다.
